**_В этой директории лежат исходные коды к тестовому клиенту написанномому на языке V._**

# Компиляция и запуск
Для компиляции клиента потребутеся скачать компилятор V (Как это сделать можно найти на официальном сайте языка [V](https://vlang.io/)).

Далее проект компилируется из директории VlangSmallTestClient командой: ``` v -d http3 run . ``` Возможно понадобится вручную влить активный МР с исправлениями, потому что http3 находится в разработке. 

# Описание
Сам клиент демонстрирует возможность подключиться к серверу на джаве из стороннего клиента на произвольном языке, написанном по нашей спецификации.
