**_В этой директории лежат исходные коды к тестовому клиенту написанномому на языке V._**

# Компиляция и запуск
Для компиляции клиента потребутеся скачать компилятор V (Как это сделать можно найти на официальном сайте языка [V](https://vlang.io/)).

Далее проект компилируется из директории VlangSmallTestClient командой: ``` v crun . ```

# Описание
Данный клиент реализует простой кодек, написанный исключительно опираясь на спецификацию протокола, и полный цикл взаимодействия с сервером по сценарию единоразовой регистрации.
Кодек умеет кодировать только **TRACKER_REGISTER_REQ** и **TRACKER_REGISTER_RES**, что достаточно для регистрации на трекере и получения ответа с него.

_Соответсвенно клиент умеет регистрироваться на сервере и получать от него ответ._

---

Данный клиент должен продемонстрировать жизнеспособность спецификации протокола, и его самого, для общения с сервером для пользования вне нашего джава приложения.

_**Сам V клиент не идет в финальную сборку и предназначен для тестирования протокола и сервера.**_
